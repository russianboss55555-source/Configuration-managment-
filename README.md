## Назначение

Программа представляет собой графический эмулятор UNIX-подобной оболочки.
Пользователь вводит команды в строке ввода и видит их результаты в истории.
REPL означает цикл «прочитать ввод → обработать → вывести результат».
Этот цикл продолжается до команды `exit` или закрытия окна.

На первом этапе реализованы интерфейс, парсер и команды-заглушки.
В дальнейшем программа будет работать с виртуальной файловой системой (VFS),
которая загружается из ZIP-архива и хранится в оперативной памяти.

## Требования и запуск

Нужен **Python 3.10 или новее с Tkinter**. Используется стандартная библиотека;
дополнительные пакеты через `pip` не требуются. Отдельная сборка отсутствует.

Проверка Python и Tkinter:

```console
python --version
python -m tkinter
```

Вторая команда должна открыть демонстрационное окно Tkinter. Для Windows
при установке Python включите компонент Tcl/Tk и добавление Python в PATH.
Для Linux Tkinter может устанавливаться отдельным пакетом дистрибутива.

**Windows:** распакуйте проект, откройте его папку и запустите `run.bat`.
Также можно открыть терминал в папке с README и выполнить:

```console
python -m src.main
```

При использовании Python Launcher в Windows допустимо:

```console
py -3 -m src.main
```

**Linux/macOS:**

```console
sh run.sh
```

Или из папки проекта:

```console
python3 -m src.main
```

Работа окна требует доступного графического сеанса. При ошибке открытия
дисплея программа выводит сообщение в терминал и возвращает код 1.

## Команды и правила разбора

| Команда | Аргументы | Поведение первого этапа |
| --- | --- | --- |
| `ls` | Ноль или один путь | Вывод имени команды и аргументов |
| `cd` | Ноль или один путь | Вывод имени команды и аргументов |
| `exit` | Без аргументов | Завершение приложения |

Флаги команд пока не поддерживаются. Путь, начинающийся с `-`, будет воспринят
как неподдерживаемый флаг. Имена команд чувствительны к регистру.
Пустая строка оставляет сеанс открытым.

Поддерживаемый синтаксис парсера:

- Пробелы и табуляции разделяют команду и аргументы.
- Двойные кавычки объединяют текст в один аргумент и допускают `$NAME`.
- Одинарные кавычки объединяют текст и сохраняют `$NAME` буквально.
- `$NAME` и `${NAME}` раскрываются в значение переменной реальной ОС.
- Значение переменной с пробелами сохраняется внутри одного аргумента.
- Отсутствующая переменная вызывает сообщение об ошибке.
- Незакрытая кавычка вызывает сообщение об ошибке.
- Подставленное значение повторно не раскрывается.

Парсер реализует учебное подмножество синтаксиса оболочки. Экранирование
обратной косой чертой, конвейеры, перенаправления, подстановка команд,
шаблоны файлов и комментарии на первом этапе не реализованы.
Обратная косая черта сохраняется как обычный символ.
Команды реальной операционной системы не запускаются.

## Примеры использования

```text
shell $ ls
[Заглушка] Команда: ls; аргументы: []

shell $ cd /documents
[Заглушка] Команда: cd; аргументы: ['/documents']

shell $ ls "my documents"
[Заглушка] Команда: ls; аргументы: ['my documents']

shell $ ls '$HOME'
[Заглушка] Команда: ls; аргументы: ['$HOME']

shell $ pwd
Ошибка: Неизвестная команда: pwd

shell $ cd first second
Ошибка: Использование: cd [путь]

shell $ ls -l
Ошибка: Флаги ls пока не поддерживаются.

shell $ exit now
Ошибка: Использование: exit

shell $ ls "unfinished
Ошибка: Незакрытая кавычка.
```

Для демонстрации окружения в Windows введите `cd "$USERPROFILE"`.
В Linux/macOS можно использовать `cd "$HOME"`. В результате отобразится
реальное значение переменной текущего процесса. Доступность конкретного
имени зависит от ОС и способа запуска программы.

Для воспроизводимого примера в PowerShell сначала выполните:

```powershell
$env:DEMO_PATH = "/demo folder"
python -m src.main
```

В открывшемся окне эмулятора выполните:

```text
shell $ cd "$DEMO_PATH"
[Заглушка] Команда: cd; аргументы: ['/demo folder']
```

В Linux/macOS при необходимости используйте `python3`.
Тесты используют временно подменённое окружение процесса и не зависят
от наличия `$HOME` или других переменных на конкретном компьютере.

При подготовке этой версии все 16 тестов прошли успешно. Также проверены
синтаксис Python, наличие docstring и ограничения длины строк и функций.
В среде подготовки отсутствовал графический дисплей, поэтому визуальная

Проверяются разбор пробелов и кавычек, пустые аргументы, раскрытие переменных,
сохранение буквального текста, ошибочный ввод, заглушки, `exit` и продолжение
работы после ошибки. Автоматические тесты проверяют логику без запуска GUI.
Открытие и визуальное поведение окна проверяются вручную по сценарию ниже.

### Ручная демонстрация первого этапа

1. Откройте приложение и проверьте имя `demo_vfs.zip` в заголовке.
2. Выполните `ls`, `ls /docs`, `cd`, `cd /docs`.
3. Выполните `ls "my documents"` и пример с переменной окружения своей ОС.
4. Проверьте неизвестную команду, лишние аргументы и незакрытые кавычки
   из раздела примеров. После ошибки снова выполните `ls`.
5. Проверьте отправку через Enter и через кнопку «Выполнить».
6. Выполните `exit now`: появится ошибка, окно останется открытым.
7. Выполните `exit`: окно закроется.

## Структура и функции

| Файл | Назначение |
| --- | --- |
| `src/main.py` | Создание окна и запуск цикла событий |
| `src/gui.py` | Графический интерфейс и передача команд оболочке |
| `src/parser.py` | Разбор строки, кавычек и переменных окружения |
| `src/shell.py` | Результат команды, заглушки, ошибки и завершение |
| `tests/test_shell.py` | 16 автоматических тестовых методов |
| `run.bat`, `run.sh` | Запуск из папки проекта |
| `.gitignore` | Исключение служебных и сгенерированных файлов |

Основные функции и методы:

| Функция / метод | Назначение |
| --- | --- |
| `main()` | Создаёт Tk, обрабатывает ошибку дисплея, запускает mainloop |
| `expand_variables(text)` | Заменяет переменные значениями окружения |
| `decode_fragment(fragment)` | Обрабатывает кавычки одного фрагмента |
| `parse_command(line)` | Возвращает список: имя команды, затем аргументы |
| `Shell.execute(line)` | Выбирает обработчик, возвращает `CommandResult` |
| `Shell.stub_command(command, arguments)` | Проверяет и выводит заглушку |
| `Shell.exit_command(arguments)` | Проверяет `exit`, задаёт should_exit |
| `TerminalWindow.__init__(root, vfs_name)` | Настраивает окно и оболочку |
| `TerminalWindow.build_widgets(vfs_name)` | Создаёт элементы интерфейса |
| `TerminalWindow.write(text)` | Добавляет результат в историю |
| `TerminalWindow.submit(event=None)` | Обрабатывает Enter или кнопку |

`CommandResult` содержит строку `output` и флаг `should_exit`.
Настройка `DEFAULT_VFS_NAME` в `src/gui.py` задаёт имя VFS в заголовке.
`MAX_PATH_ARGUMENTS` в `src/shell.py` ограничивает число аргументов заглушек.
Параметры командной строки появятся на втором этапе.
